# Extraits des polices latines

Extraits bruts de `input/roms/englishrom.gba`, sans ROM complète : pour chaque
police, 256 glyphes suivis des 256 largeurs. Bases : 1EAF00, 1F3100, 1FF300,
20F618, 21F930 ; strides : 32, 64, 64, 64, 64. Voir `src/core/font_glyphs.py`
pour les littéraux moteur qui désignent les tables vivantes.
