# PT-BR — PT-07 : lexique Easy Chat (F-766)

Les 281 offsets explicites du manifeste sont couverts, sans suppression ni édition
hors lot dans les sources de traduction. F-758 et F-759 sont intégrés. Le domaine
réel est le lexique Easy Chat (groupes 4 à 10), et non les boutons des menus.
Le glossaire F-759 ne contient pas de nom propre ou de terme spécialisé à substituer
ici ; les mots ordinaires sont traduits directement depuis EN avec comparaison FR.
« DAUGHTER » devient FILHA, « Close » adjectival PERTO, « MEET YOU » TE CONHECER.
Les interjections communes et RIVAL peuvent conserver leur forme anglaise.

Chaque mot est référencé par une cellule de 12 octets (pointeur, rang, disponibilité).
Les sept tables sont atteintes depuis gEasyChatGroups à 0x3eced4 ; sept littéraux
moteur pointent sur cette racine (0x0bd788, 0x0bd7c0, 0x0bd84c, 0x0bda38,
0x0bdd2c, 0x0be270, 0x0be414). Les tests vérifient cette chaîne, chaque cible vivante,
les huit octets de métadonnées et l'encodage strict terminé par FF.
Il n'y a aucun placeholder, code de contrôle ou saut de page dans les 281 sources EN.

Aucune cellule n'est une table de caractères de largeur fixe : les chaînes sont
relogeables via leur pointeur propre. Aucun patch dédié n'est donc requis ; aucune
entrée ignorée n'est revendiquée comme injectée. Les textes sont limités à 12 glyphes,
59 pixels dans la petite police et 72 dans les quatre autres, soit les maxima EN.
Le JSON [pt07_audit.json](../../languages/pt/data/pt07_audit.json) conserve EN, FR, PT,
les octets encodés, les cinq mesures, les descripteurs et les cibles après build.

## Validation

- `make build-pt`, puis tests ROM `tests/e2e/pt/test_batch_pt07_rom.py`.
- Tests de protection et de sens : `tests/unit/pt/test_batch_pt07.py` et
  `tests/unit/test_translation_integrity.py`.
- Playwright hors écran : `playwright.pt07.config.ts`, mots IRMÃO et O SUFICIENTE
  lus aux cibles Easy Chat du build et rendus par le moteur mGBA dans une msgbox.
  Assertions : octets exacts, motif du tilde Ã, encre présente, largeur et absence
  de débordement. Seul le script de déclenchement est ajouté à une copie temporaire.
  Captures hors dépôt, jointes au ticket ; aucune sauvegarde en jeu.
- Hooks actifs : suites Python/Vitest et reconstructions FR/IT/DE.

Résultats sur le build contrôlé : 39 tests ciblés réussis, 2 tests Playwright
réussis. Lint Ruff et TypeScript réussis. Les hooks ont également exécuté les
suites rapides Python/Vitest et les builds FR/IT/DE avec succès.

## Non vérifié

La navigation interactive dans le sélecteur Easy Chat natif et toutes les
combinaisons possibles de phrases ne sont pas certifiées par la sonde msgbox.
Le bilan binaire porte sur chaque mot et toutes les métadonnées des cellules visées.
Aucun changement du moteur partagé, aucune ROM ni capture committée, aucun push
et aucune exécution de pipeline distant.
