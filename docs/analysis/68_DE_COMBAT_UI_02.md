# B-668 — Qualification combat_ui-02

Périmètre fermé : les 300 offsets du ticket, dernière occurrence gagnante EN/FR/DE. Aucun audit global relancé. Les ROM sources sont lues sans écriture. Aucune ressource de traduction ni patch FR/IT modifié ; parity.yaml enregistre uniquement les nouveaux tests DE.

## Méthode et portée de la preuve

Les commandes sont décodées avec leurs arguments (FC, FD, F7, F8, F9). Les guillemets du décodeur naïf à la place de 0xB0 ne sont pas pris pour du texte. Tous les pointeurs absolus EN vers un offset corrigé sont suivis à la même position dans la ROM DE construite. Les fixtures figent préimages EN, sites et octets DE attendus ; le test ROM conserve les arguments, la ponctuation, les glyphes et les pages FB et tolère uniquement le ré-enveloppement FE/FA et les espaces. Les sources gardent l’ordre des placeholders.

Les champs de largeur ci-dessous sont la largeur maximale du texte statique (buffers retirés), pas une borne sur un nom injecté au runtime. Les cas de combat corrigés ont aussi un test avec deux noms de neuf glyphes larges (54 px chacun). Les quatre mémos conservent trois lignes, avec leur ligne statique ramenée de 206–207 à 178 px. Les tables d’étages sont repointées, jamais débordées en place. Le tutoriel conserve le tutoiement de Log ; aucun buffer Sohn/Tochter n’est présent dans ce lot.

La preuve Playwright rend les catégories GRÜSSE et GEFÜHLE avec mGBA hors écran, depuis leurs cibles réellement repointées, dans une boîte de sonde temporaire. OCR et assertions d’octets sont requis avant capture. Le menu Nutzen est également ouvert par navigation réelle depuis une copie de sauvegarde, sans sauvegarde en jeu. Ce test prouve police/texte/moteur ; il ne prétend pas parcourir naturellement les 300 scènes héritées.

## Non vérifié

Les 300 scènes n’ont pas été parcourues naturellement dans l’émulateur. Les deux catégories sont rendues via une sonde de script sur une copie temporaire de ROM ; le troisième écran provient de la navigation réelle. Les largeurs statiques ne prouvent pas toutes les combinaisons de noms dynamiques. Les cinq alias Pokédex, le contournement de la Pension et le helper TOXIC restent explicitement réservés à une qualification ou un patch séparé, comme détaillé par offset.

## Exclusions techniques

- Les cinq alias Pokédex 0x415D45/4F/5E/77/8A commencent avant leurs chaînes réellement pointées. Leurs véritables débuts sont hors liste : pas de chevauchement silencieux avec un autre lot.
- 0x416244 conserve le contournement anglais anti-gel de la Pension ; un correctif moteur et un replay de retrait sont nécessaires avant de lever le garde.
- 0x417920 reste non modifié : le lecteur indirect éventuel du helper TOXIC doit être établi avant un patch de table.
- Noms de lieux, espèces et crédits EN explicitement voulus restent inchangés. Kanto sans pointeur n’est pas déclaré mort.
- Aucun push, aucune exécution distante ; les reconstructions déclenchées par les hooks sont locales.
